# 反向法式

## 美甲反向法式是什麼？中階入門攻略
反向法式是把法式白邊從『指尖』反過來畫在『指根』，像一彎月牙，日系新鮮款。

## 反向法式原理與辨識重點：美甲師不說的色在指根
一般法式是『透明底＋指尖白邊』，反向法式剛好顛倒——顏色塊放在指根，開口朝著指尖。看起來像指甲根部畫了一道微笑反過來的弧，反而把視線拉到指根，讓指甲看起來比較短、比較可愛，適合本甲偏長的人修飾比例。

## 誰適合做反向法式？新鮮感對號入座
想要『看起來像法式、又跟別人不一樣』的人；日系風、清新款常指定，本甲長、想縮短視覺的人很合。

## 反向法式美甲施作步驟：指根色塊
上好底色照燈 → 在指根處貼月牙貼紙或徒手畫一彎弧 → 上色 → 把弧補順 → 照燈 → 可加一條細線或小鋼珠 → 封層。

## 反向法式優缺點分析：美甲持久度與傷甲評估
| 優點 | 說明 |
| --- | --- |
| 新鮮感十足，拍照很上相，比傳統法式更有設計感。 | 是日系流派的招牌，中階就能上手 |
| 缺點 | 說明 |
| 指根那彎弧畫對稱很難，跟微笑線法式一樣考驗手穩。 | 前置與弧畫太大會蓋過半個指甲、看起來像『生病的月牙』；畫太小又沒有反向的味道。建議先在指甲上用筆輕畫定位，再上色。沒顧好會打折 |

## 反向法式新手雷區：開口向指尖與常見錯誤
> 注意：弧畫太大會蓋過半個指甲、看起來像『生病的月牙』；畫太小又沒有反向的味道。建議先在指甲上用筆輕畫定位，再上色。

## 反向法式和其他美甲做法的差別比較
常跟霧面、跳色配——黑霧面底＋金屬色反向月牙，立刻有個性；也常跟珍珠一起貼在弧線中央點綴。

## 反向法式美甲常見問題 FAQ
Q：反向法式適合短甲嗎？
A：短甲反而更適合，因為它把視線往指根帶、指尖露出，看起來手指修長。長甲做會有種『反過來』的怪異。

Q：可以跟一般法式混搭嗎？
A：可以。一隻手兩指做反向、兩指做正向、一指純色，就是現在很紅的不對稱設計。
