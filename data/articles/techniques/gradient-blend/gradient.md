# 漸層

## 認識漸層：中階快速導讀
漸層是用海綿或刷子把兩種顏色疊出『由深到淺』的自然過渡，粉嫩又耐看，日系最愛。

## 漸層的原理與辨識重點：色由深到淺
把兩個或三個顏色，用海綿輕輕按壓，讓色與色的邊界慢慢暈開，形成像是天空或腮紅那樣的漸層感。顏色愈多、過渡愈長，變化愈多。

## 誰適合做漸層？經典不敗
這套做法主要適合「經典不敗」的場合與族群。如果你是日系美甲的愛好者，或正處在中階階段的學習者，都很值得先把它認識起來——它會是你判斷其他款式的地基。

## 漸層施作步驟：海綿／刷漸層
先上底色 → 海綿沾色、輕按在甲面 → 一層層疊出深淺 → 等乾或照燈 → 上封層。海綿用前先沾濕一點，粉會更自然。

## 漸層優點與缺點分析
| 面向 | 說明 |
| --- | --- |
| 好上手 | 中階階段就能掌握，是日系流派的入門招牌 |
| 辨識度高 | 靠「色由深到淺」一眼認得出，成品是粉嫩漸層 |
| 變化多 | 可延伸出多種「經典不敗」的變化款 |
| 注意 | 「色由深到淺」與包邊沒顧好，持久度會打折 |

## 漸層新手雷區：海綿按壓
> 注意：海綿太乾會留死邊、太濕又暈成一團。按壓要『輕而多』，不要用力壓一次到位。

## 漸層和相似做法的差別
漸層最常被拿來和「暈染、水彩暈染」搞混。簡單分：漸層更執著在「色由深到淺」這一個細節上，而隔壁那幾種把重點放在別的地方——同一個美甲領域、不同的側重點，看多了自然分得開。

## 漸層常見問題 FAQ
Q：初學者怎麼認識漸層？
A：先看粉嫩漸層這個成品，找「色由深到淺」在哪裡，再對照上面的說明，重複兩三次就有直覺了。

Q：漸層和我平常做的美甲有什麼關係？
A：它是「經典不敗」裡很常用的一環，很多日系款式都吃它的技巧。會了它，你看美甲的判斷力會明顯變好。

Q：一定要買很貴的器材嗎？
A：不用。先用入門器材把「色由深到淺」練穩，再看要不要升級。技術永遠比器材重要。

Q：哪種場合最適合用漸層？
A：需要「經典不敗」氛圍的場合最合適。日常或特殊活動都能駕馭，重點是配色與厚薄要掌握好。
