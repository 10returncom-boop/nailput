# 補甲與覆蓋

## 美甲補甲與覆蓋是什麼？入門入門攻略
指甲斷到歪七扭八？不用整片重做，覆蓋一層保護膜就救回來。

## 補甲與覆蓋原理與辨識重點：美甲師不說的覆蓋本甲
有時候你不想留長甲，只是想要指甲別再斷。這時就做 overlay：輕磨甲面後上一層薄凝膠（或硬膠），把整個本甲包起來，像幫指甲穿一件防彈衣。斷甲、薄甲、分層甲最適合；不延長、純補強。

## 誰適合做補甲與覆蓋？修補斷甲對號入座
本甲很薄、容易斷、常咬甲或剝指甲油的人；也是很多客人回店的固定保養項目。

## 補甲與覆蓋美甲施作步驟：凝膠補強
前置修型 → 輕磨甲面去光 → 斷甲處先修剪平整 → 上薄底膠 → 上一層薄硬膠或建構膠（壓力點要夠厚）→ 照燈 → 修型封層。

## 補甲與覆蓋優缺點分析：美甲持久度與傷甲評估
| 優點 | 說明 |
| --- | --- |
| 不延長、看起來像自己指甲；卻能立刻讓薄甲變耐操，工作打字不卡。 | 是通用流派的招牌，入門就能上手 |
| 缺點 | 說明 |
| 因為沒有延長，視覺上沒有變長變漂亮，純粹是功能性保養。 | 前置與別把 overlay 做成厚厚一層——它要薄而強，太厚會悶、會翹；也別跳過壓力點加厚，那是最容易斷的地方。沒顧好會打折 |

## 補甲與覆蓋新手雷區：補強不延長與常見錯誤
> 注意：別把 overlay 做成厚厚一層——它要薄而強，太厚會悶、會翹；也別跳過壓力點加厚，那是最容易斷的地方。

## 補甲與覆蓋和其他美甲做法的差別比較
跟「紙模延長」不同：延長是加長度；overlay 是只補強、不加長。客人不想留長，就做 overlay。

## 補甲與覆蓋美甲常見問題 FAQ
Q：Overlay 可以撐多久？
A：正常 2–3 週回補；薄甲族建議固定做，半年後甲質明顯變厚變健康。

Q：做 overlay 還會斷嗎？
A：正確施作後斷裂機率大降；但若客人本身營養差、常泡水，還是要配合指緣保養。
