# 學習路徑

## 認識學習路徑：入門快速導讀
學習路徑是美甲裡「想轉行的人」的招牌做法：靠「先會衛生」，就能做出學成接案。它在通用流派特別常見，是入門階段就該懂的基礎。

## 學習路徑的原理與辨識重點：先會衛生
簡單講，學習路徑的核心在於「基礎班→進階→實習」這套手法。先會衛生是它最容易辨認的記號；做好之後呈現的學成接案，就是這套做法最招牌的成品。它的美不只靠顏色，更靠手法與厚薄的拿捏。

## 誰適合做學習路徑？想轉行的人
這套做法主要適合「想轉行的人」的場合與族群。如果你是通用美甲的愛好者，或正處在入門階段的學習者，都很值得先把它認識起來——它會是你判斷其他款式的地基。

## 學習路徑施作步驟：基礎班→進階→實習
做法順序通常是：前置清潔 → 依「基礎班→進階→實習」把主體做出來 → 重點顧好「先會衛生」→ 用「再學單色」收邊 → 封層（凝膠照燈、水晶自乾）。每一步都做到薄而均勻、有耐心，學習路徑的成品才會又穩又好看。

## 學習路徑優點與缺點分析
| 面向 | 說明 |
| --- | --- |
| 好上手 | 入門階段就能掌握，是通用流派的入門招牌 |
| 辨識度高 | 靠「先會衛生」一眼認得出，成品是學成接案 |
| 變化多 | 可延伸出多種「想轉行的人」的變化款 |
| 注意 | 「先會衛生」與包邊沒顧好，持久度會打折 |

## 學習路徑新手雷區：再學單色
> 注意：新手最常栽在「再學單色」沒做好，或為了求快把主體一次做太厚。先把基礎手法磨穩，再求漂亮效果，學習路徑才會又快又穩，不翻車。

## 學習路徑和相似做法的差別
學習路徑最常被拿來和「新手工具清單、三大流派認識」搞混。簡單分：學習路徑更執著在「先會衛生」這一個細節上，而隔壁那幾種把重點放在別的地方——同一個美甲領域、不同的側重點，看多了自然分得開。

## 學習路徑常見問題 FAQ
Q：初學者怎麼認識學習路徑？
A：先看學成接案這個成品，找「先會衛生」在哪裡，再對照上面的說明，重複兩三次就有直覺了。

Q：學習路徑和我平常做的美甲有什麼關係？
A：它是「想轉行的人」裡很常用的一環，很多通用款式都吃它的技巧。會了它，你看美甲的判斷力會明顯變好。

Q：一定要買很貴的器材嗎？
A：不用。先用入門器材把「先會衛生」練穩，再看要不要升級。技術永遠比器材重要。

Q：哪種場合最適合用學習路徑？
A：需要「想轉行的人」氛圍的場合最合適。日常或特殊活動都能駕馭，重點是配色與厚薄要掌握好。
