# 交叉感染防護

## 一句話搞懂
交叉感染防護是美甲裡「顧客安全」的招牌做法：靠「一人一套工具」，就能做出安心服務。它在通用流派特別常見，是中階階段就該懂的基礎。

## 它到底是什麼
簡單講，交叉感染防護的核心在於「拋棄式工具＋隔離」這套手法。一人一套工具是它最容易辨認的記號；做好之後呈現的安心服務，就是這套做法最招牌的成品。它的美不只靠顏色，更靠手法與厚薄的拿捏。

## 適合誰、什麼場合用
這套做法主要適合「顧客安全」的場合與族群。如果你是通用美甲的愛好者，或正處在中階階段的學習者，都很值得先把它認識起來——它會是你判斷其他款式的地基。

## 怎麼做
做法順序通常是：前置清潔 → 依「拋棄式工具＋隔離」把主體做出來 → 重點顧好「一人一套工具」→ 用「手套與口罩」收邊 → 封層（凝膠照燈、水晶自乾）。每一步都做到薄而均勻、有耐心，交叉感染防護的成品才會又穩又好看。

## 優點與缺點
| 面向 | 說明 |
| --- | --- |
| 好上手 | 中階階段就能掌握，是通用流派的入門招牌 |
| 辨識度高 | 靠「一人一套工具」一眼認得出，成品是安心服務 |
| 變化多 | 可延伸出多種「顧客安全」的變化款 |
| 注意 | 「一人一套工具」與包邊沒顧好，持久度會打折 |

## 新手常見雷區
> 注意：新手最常栽在「手套與口罩」沒做好，或為了求快把主體一次做太厚。先把基礎手法磨穩，再求漂亮效果，交叉感染防護才會又快又穩，不翻車。

## 容易搞混的相似做法
交叉感染防護最常被拿來和「消毒滅菌流程、銼刀與打磨」搞混。簡單分：交叉感染防護更執著在「一人一套工具」這一個細節上，而隔壁那幾種把重點放在別的地方——同一個美甲領域、不同的側重點，看多了自然分得開。

## 常見問題
Q：初學者怎麼認識交叉感染防護？
A：先看安心服務這個成品，找「一人一套工具」在哪裡，再對照上面的說明，重複兩三次就有直覺了。

Q：交叉感染防護和我平常做的美甲有什麼關係？
A：它是「顧客安全」裡很常用的一環，很多通用款式都吃它的技巧。會了它，你看美甲的判斷力會明顯變好。

Q：一定要買很貴的器材嗎？
A：不用。先用入門器材把「一人一套工具」練穩，再看要不要升級。技術永遠比器材重要。

Q：哪種場合最適合用交叉感染防護？
A：需要「顧客安全」氛圍的場合最合適。日常或特殊活動都能駕馭，重點是配色與厚薄要掌握好。
