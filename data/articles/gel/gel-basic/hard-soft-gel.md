# 硬膠與軟膠

## 認識硬膠與軟膠：中階快速導讀
硬膠耐撞但只能磨卸，軟膠好卸但較軟；做延甲要先想好你要『撐力』還是『好卸』。

## 硬膠與軟膠的原理與辨識重點：硬膠要磨不能泡
凝膠照『硬度』分：硬膠固化後非常硬、撐力強，適合做延長，但卸甲得用磨的；軟膠／可撓膠較軟、有彈性，泡卸水就能卸，適合加固薄甲。

## 誰適合做硬膠與軟膠？做延甲前必懂
這套做法主要適合「做延甲前必懂」的場合與族群。如果你是日系美甲的愛好者，或正處在中階階段的學習者，都很值得先把它認識起來——它會是你判斷其他款式的地基。

## 硬膠與軟膠施作步驟：硬膠／軟膠／可撓膠
要延長、撐力優先 → 選硬膠；只是加固本甲、薄甲易斷 → 選軟膠或可撓膠。施作方式類似，但硬膠要刻意『厚薄分明』才不會斷。

## 硬膠與軟膠優點與缺點分析
| 面向 | 說明 |
| --- | --- |
| 好上手 | 中階階段就能掌握，是日系流派的入門招牌 |
| 辨識度高 | 靠「硬膠要磨不能泡」一眼認得出，成品是延甲與本甲加固 |
| 變化多 | 可延伸出多種「做延甲前必懂」的變化款 |
| 注意 | 「硬膠要磨不能泡」與包邊沒顧好，持久度會打折 |

## 硬膠與軟膠新手雷區：軟膠可卸
> 注意：把軟膠拿去做長延甲，很快就軟掉或斷裂；把硬膠拿來直接泡卸水，泡半天也卸不掉。先想清楚用途再選材。

## 硬膠與軟膠和相似做法的差別
硬膠與軟膠最常被拿來和「凝膠是什麼、光療燈原理」搞混。簡單分：硬膠與軟膠更執著在「硬膠要磨不能泡」這一個細節上，而隔壁那幾種把重點放在別的地方——同一個美甲領域、不同的側重點，看多了自然分得開。

## 硬膠與軟膠常見問題 FAQ
Q：初學者怎麼認識硬膠與軟膠？
A：先看延甲與本甲加固這個成品，找「硬膠要磨不能泡」在哪裡，再對照上面的說明，重複兩三次就有直覺了。

Q：硬膠與軟膠和我平常做的美甲有什麼關係？
A：它是「做延甲前必懂」裡很常用的一環，很多日系款式都吃它的技巧。會了它，你看美甲的判斷力會明顯變好。

Q：一定要買很貴的器材嗎？
A：不用。先用入門器材把「硬膠要磨不能泡」練穩，再看要不要升級。技術永遠比器材重要。

Q：哪種場合最適合用硬膠與軟膠？
A：需要「做延甲前必懂」氛圍的場合最合適。日常或特殊活動都能駕馭，重點是配色與厚薄要掌握好。
