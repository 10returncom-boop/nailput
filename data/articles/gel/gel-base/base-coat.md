# 底膠的功用

## 認識底膠的功用：入門快速導讀
底膠是色膠和真甲之間的『接著劑』，上得對，整副凝膠才貼得住、不翹。

## 底膠的功用的原理與辨識重點：底膠是黏合層
底膠負責把凝膠牢牢黏在甲面上，同時隔離色素，避免深色把指甲染黃。它薄薄一層，像雙面膠一樣把上面的色膠和下面的真甲黏在一起。

## 誰適合做底膠的功用？別再跳過底膠
這套做法主要適合「別再跳過底膠」的場合與族群。如果你是通用美甲的愛好者，或正處在入門階段的學習者，都很值得先把它認識起來——它會是你判斷其他款式的地基。

## 底膠的功用施作步驟：酸蝕／免磨／可撓底膠
清潔甲面油脂 → 薄上底膠 → 記得包邊（把甲緣也帶到）→ 照燈。底膠不要貪厚，厚了反而浮、反而不牢。

## 底膠的功用優點與缺點分析
| 面向 | 說明 |
| --- | --- |
| 好上手 | 入門階段就能掌握，是通用流派的入門招牌 |
| 辨識度高 | 靠「底膠是黏合層」一眼認得出，成品是持久不翹 |
| 變化多 | 可延伸出多種「別再跳過底膠」的變化款 |
| 注意 | 「底膠是黏合層」與包邊沒顧好，持久度會打折 |

## 底膠的功用新手雷區：厚度要薄
> 注意：很多人跳過底膠直接上色，結果整片掉。另一常見錯誤是底膠沒包邊，前端很快起翹。底膠是地基，地基歪了上面全倒。

## 底膠的功用和相似做法的差別
底膠的功用最常被拿來和「封層的選擇、可撓性底膠」搞混。簡單分：底膠的功用更執著在「底膠是黏合層」這一個細節上，而隔壁那幾種把重點放在別的地方——同一個美甲領域、不同的側重點，看多了自然分得開。

## 底膠的功用常見問題 FAQ
Q：可以不上底膠嗎？
A：短時間可以，但持久度差很多，深色也容易染甲。底膠幾十塊錢，別省這一步。

Q：底膠要照多久？
A：依產品標示，一般 30–60 秒。照不足，底膠沒固化就上色，整層都會不牢。
