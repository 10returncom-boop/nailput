# 取粉成珠技巧

## 一句話搞懂
取粉成珠是水晶的基本功：筆沾液、點粉、讓它自己凝成一顆小圓珠，練熟了整隻手都會順。

## 它到底是什麼
一顆好的『珠』是水晶漂亮與否的關鍵。液體太多珠會塌、太乾會散。訣竅是讓粉自己吸液、慢慢凝結，而不是用力去攪。

## 適合誰、什麼場合用
這套做法主要適合「新手卡關點」的場合與族群。如果你是歐美美甲的愛好者，或正處在中階階段的學習者，都很值得先把它認識起來——它會是你判斷其他款式的地基。

## 怎麼做
做法順序通常是：前置清潔 → 依「取珠三階段」把主體做出來 → 重點顧好「筆沾液再沾粉」→ 用「珠要圓」收邊 → 封層（凝膠照燈、水晶自乾）。每一步都做到薄而均勻、有耐心，取粉成珠技巧的成品才會又穩又好看。

## 優點與缺點
| 面向 | 說明 |
| --- | --- |
| 好上手 | 中階階段就能掌握，是歐美流派的入門招牌 |
| 辨識度高 | 靠「筆沾液再沾粉」一眼認得出，成品是標準小圓珠 |
| 變化多 | 可延伸出多種「新手卡關點」的變化款 |
| 注意 | 「筆沾液再沾粉」與包邊沒顧好，持久度會打折 |

## 新手常見雷區
> 注意：別一直用筆尖攪粉，那會把珠攪出氣泡、也攪太散。讓它自然凝、輕輕帶，才是對的。

## 容易搞混的相似做法
取粉成珠技巧最常被拿來和「水晶粉與液體、單體與聚合」搞混。簡單分：取粉成珠技巧更執著在「筆沾液再沾粉」這一個細節上，而隔壁那幾種把重點放在別的地方——同一個美甲領域、不同的側重點，看多了自然分得開。

## 常見問題
Q：初學者怎麼認識取粉成珠技巧？
A：先看標準小圓珠這個成品，找「筆沾液再沾粉」在哪裡，再對照上面的說明，重複兩三次就有直覺了。

Q：取粉成珠技巧和我平常做的美甲有什麼關係？
A：它是「新手卡關點」裡很常用的一環，很多歐美款式都吃它的技巧。會了它，你看美甲的判斷力會明顯變好。

Q：一定要買很貴的器材嗎？
A：不用。先用入門器材把「筆沾液再沾粉」練穩，再看要不要升級。技術永遠比器材重要。

Q：哪種場合最適合用取粉成珠技巧？
A：需要「新手卡關點」氛圍的場合最合適。日常或特殊活動都能駕馭，重點是配色與厚薄要掌握好。
